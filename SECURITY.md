# Security

Report vulnerabilities privately to the repository owner using GitHub private vulnerability reporting if enabled. Do not publish exploit details or sensitive data in issues.

Require HTTPS, secure sessions, scoped expiring invitations and signed URLs, per-resource authorization, bounded archive extraction, malware quarantine and rate limits. Exclude sensitive metadata from search by default. Server-indexed conversations are not end-to-end encrypted. Never commit credentials. Test access revocation, archive traversal and cross-user search isolation before release.
