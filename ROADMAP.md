# Roadmap

1. Foundation: repository tooling, responsive shell, database migrations, authentication and CI.
2. Chat: private/group messaging, QR invitations, reconnect and authorization.
3. Transfers: multipart upload, range downloads, persistent queues, pause/resume, retries and network policy.
4. Compression: original, ZIP, capability-gated 7z presets, media compression and archive manifests.
5. Search: authorized metadata, document text and archive entries; multilingual tests.
6. Release: browser matrix, security tests, backup/restore, observability and deployment documentation.
7. Later: direct LAN/P2P, guest sharing, E2EE with client-side search, OCR and transcription.

PRD.md governs priorities and acceptance criteria. The [implementation tracker](docs/progress.md) records Phase 1 coverage and open release gates.
