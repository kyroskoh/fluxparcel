# Roadmap

[PRD.md](PRD.md) governs priorities and acceptance criteria. [docs/progress.md](docs/progress.md) records what each
P0 requirement covers today and which release gates remain open.

| Phase | Scope | Status |
|---|---|---|
| 1. Foundation | Repository tooling, responsive shell, database migrations, authentication and CI | ✅ Done |
| 2. Chat | Private and group messaging, QR invitations, reconnect, receipts, edits and member administration | ✅ Done |
| 3. Transfers | Multipart uploads, Range downloads, persisted uploads, pause/resume, retries, expiry, storage lifecycle, network policy, priorities and batch actions | 🚧 In progress: data budgets, bandwidth caps and malware scanning remain |
| 4. Compression | Original, ZIP, capability-gated 7z presets, media compression and archive manifests | 🗓️ Planned |
| 5. Search | Authorized metadata, document text and archive entries; multilingual tests | 🗓️ Planned |
| 6. Release | Browser matrix, security tests, backup and restore, observability and deployment documentation | 🗓️ Planned |
| 7. Later | Direct LAN/P2P, guest sharing, end-to-end encryption with client-side search, OCR and transcription | 💡 Future |
